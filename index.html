규칙을 정하는 쪽

아이의 사용 현황을 보고 규칙을 정합니다. 이 기기는 감시하지 않습니다.

  1. 위 버튼으로 설치 파일을 받아 설치합니다
  2. 앱을 열고 「보호자로 시작」 을 누릅니다
  3. 알림 권한을 허용 합니다
  4. 아이 폰에 뜬 연결 코드 12자리와 승인 코드 4자리를 입력하면 연결됩니다
아이 휴대폰

규칙이 적용되는 쪽

사용시간을 측정하고 약속한 규칙에 따라 앱을 차단합니다.

  1. 같은 파일을 받아 설치합니다
  2. 앱을 열고 「아이 기기로 설정」 을 누릅니다
  3. 화면에 연결 코드 12자리와 승인 코드 4자리가 표시됩니다. 「연결 코드 복사」 로 보호자에게 보내주세요
  4. 권한 5가지를 순서대로 켭니다 (설정 화면으로 이동합니다)
  5. 마지막에 보호자 PIN 을 정합니다. 이후 이 화면을 열 때 필요합니다

유해 사이트 차단 (선택)

아이 폰에서 한 번만 설정하면 기기 전체에 적용됩니다.

설정 > 연결 > 기타 연결 설정 > 비공개 DNS > 비공개 DNS 공급자 호스트 이름 > family.cloudflare-dns.com

설치 전에 알아두세요
  • 스토어를 거치지 않아 “출처를 알 수 없는 앱” 경고가 나옵니다. 파일을 탭한 뒤 이 출처 허용을 눌러주세요
  • 삼성 휴대폰은 두 번 더 물어봅니다 — 「앱 설치가 권장되지 않음」 → 무시하고 설치, 「앱 검사 권장됨」 → 세부정보 더보기 → 검사 없이 설치
  • 접근성 스위치가 켜지지 않으면 앱 정보 화면 오른쪽 위 ⋮ → 「제한된 설정 허용」 을 먼저 눌러주세요. 안드로이드 13부터 스토어 밖에서 설치한 앱을 이렇게 막습니다
  • 아이 폰에서 기기 관리자를 켜면 앱 삭제가 막힙니다. 지우려면 아이 폰의 폰약속에서 보호자 설정(PIN) → 「보호 종료하고 앱 삭제 준비」 를 누른 뒤 삭제하세요
  • 공장초기화나 PC 연결로는 해제될 수 있습니다. 완벽한 차단 도구가 아닙니다
  • 아직 정식 출시 전 버전입니다
사용 기록은 보호자만 볼 수 있는 데이터베이스에 저장되며, 외부에 제공되지 않습니다.
